About Me

เกี่ยวกับตัวผมและสิ่งที่ผมทำ

สวัสดีครับ ผม ศุภโชค ไพดี (SUPACHOK PAIDEE) — นักพัฒนาซอฟต์แวร์ผู้หลงใหลในการสร้างสรรค์เทคโนโลยี ครอบคลุมทั้งด้าน Full Stack Development, Artificial Intelligence และ Data Science

ตลอดเส้นทางการทำงาน ผมได้พัฒนาเว็บแอปพลิเคชัน, ระบบ API, โมเดล Machine Learning ไปจนถึง Dashboard สำหรับวิเคราะห์ข้อมูล โดยผสมผสานเทคโนโลยีทั้งฝั่ง Frontend และ Backend เพื่อส่งมอบโซลูชันที่ตอบโจทย์การใช้งานจริง

ผมมีประสบการณ์ตรงจากการฝึกงานในหน่วยงานภาครัฐ ซึ่งได้ใช้ Power BI ในการออกแบบและพัฒนา Dashboard สำหรับวิเคราะห์และนำเสนอข้อมูลให้เข้าใจง่าย ช่วยสนับสนุนการตัดสินใจได้อย่างมีประสิทธิภาพ

ผมให้ความสำคัญกับคุณภาพของงานในทุกรายละเอียด และเชื่อว่าการเรียนรู้ไม่มีวันสิ้นสุด — จึงพร้อมเปิดรับเทคโนโลยีใหม่ๆ อยู่เสมอ เพื่อพัฒนาตัวเองและสร้างผลงานที่ดียิ่งขึ้นในทุกโปรเจกต์ หากสนใจรายละเอียดผลงานเพิ่มเติม สามารถดูได้ที่ CV
